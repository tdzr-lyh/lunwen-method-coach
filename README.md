# 论文有方 方法学习任务站

外卖平台用户画像论文的任务式学习网站：11模块、33组任务、99道自测题，包含站内讲解、例题、口述自检、错题与笔记、方法交互实验。

## 网站

https://tdzr-lyh.github.io/lunwen-method-coach/

本仓库仅包含公开网站的静态资源和公开客户端配置，不含论文原始文件、用户CSV、实验数据库、特权密钥或真实学习记录。

## 跨设备同步

电脑、平板、手机登录同一邮箱账号即可同步任务、答案、口述核对、笔记与错题。可使用原雅思学习站的邮箱账号；两站进度独立。电脑首次登录后点击“同步本机原进度”，待顶部显示“已同步”后，其他设备登录即可恢复。未登录时仅保存在当前浏览器。

离线草稿按账号保存在本机，恢复联网后核对云端版本；两端同时修改发生冲突时，保留草稿并让使用者选择版本，旧版本不会静默覆盖云端。学习记录存储在启用行级权限的独立云端表中，不提交到公开仓库。

## 进度迁移

由旧chatgpt.site地址迁入时，先在旧站“学习记录”导出JSON备份，再到本站导入并确认替换。浏览器按域名保存localStorage，记录不会自动跨域迁移。
